# Audio Streamer - Roadmap

This document outlines the planned features and enhancements for the Audio Streamer project.

---

## Planned Features

### Multiple Bitrates
Offer listeners the ability to choose streaming quality based on their connection speed. Support for different bitrates (128k, 192k, 320k) will allow users on slower connections to listen without buffering while high-quality audio remains available for those with fast connections.

### Icecast/Shoutcast Compatibility
Enable integration with standard streaming servers like Icecast and Shoutcast. This will allow radio station owners to leverage existing streaming infrastructure and reach wider audiences through established streaming networks.

### Queue Management
Enhanced playlist management with drag-and-drop reordering, priority levels, shuffle functionality, and the ability to save and load playlists. This will give DJs more control over their broadcast sets and make playlist organization more intuitive.

### REST API
Provide a comprehensive REST API for remote control and integration with external systems. This will enable automation, third-party integrations, and programmatic control of the radio station without using the web interface.

### Stream Quality Metrics
Real-time monitoring of stream quality including packet loss, buffer health, connection drops, and bitrate statistics. A dashboard will visualize these metrics and alert administrators when quality degrades.

### Webhook Support
Send event notifications to external systems via webhooks. This will allow integration with monitoring tools, social media platforms, and custom automation systems when events like stream start/stop or track changes occur.

### Scheduled Broadcasting
Automated scheduling of stream start and stop times with support for recurring schedules. This will allow radio stations to run automatically at predefined times without manual intervention.
